# 탐색적 예비실험 프로토콜 v1

기록일: 2026-10-23 (Asia/Seoul). 이 문서는 첫 과제 성능 확인 전에 작성했다.
외부 사전등록 서비스에 등록한 문서는 아니다. 확인 실험은 별도 등록해야 한다.

## 범위와 질문

기획안의 최소 범위인 A(0~10 수량 판독), B(단일 집합에서 순차 두 집합으로의 전이),
방향성 연결 정도 보존 재배선 20개를 실행한다. C는 같은 합의 교환쌍을 묶은
분할과 소량 덧셈 학습 곡선을 제공한다. D의 생물학적 해석은 입력 대응 검토 전까지 보류한다.

## 성능과 무관한 회로 선택

FlyWire FAFB v783, 주석 v2.1.0, Zenodo 21549559 v1.0.0의 가공된 실제 연결망을 사용한다.
이 자료는 연결 뉴런쌍별 시냅스 개수이다. 생리학적 시냅스 강도 측정값이 아니다.
오른쪽 망막의 기탁된 평면 좌표를 각 축의 전체 범위로 정규화한다.
두 축 모두 [0.30, 0.70]에 속하는 망막 뉴런을 입력으로 선택한다.
입력 뉴런의 직접 출력 중 오른쪽 optic/visual_projection/visual_centrifugal 뉴런,
오른쪽 LC11/LC10a 전체, 그들의 직접 입력 중 같은 시각 분류에 속하는 뉴런의 합집합을 선택한다.
선택 집합의 유도 부분 그래프를 만들며 연결당 시냅스 5개 미만 및 자기 연결은 제외한다.
가공 자료의 병렬 행은 뉴런쌍별 시냅스 수를 합한 뒤 최소 개수 기준을 적용한다.
이 수정은 첫 실행의 재배선 오류를 해결한 데이터 구조 수정이며 `data_quality_log.md`에 남겼다.
선택·제외 뉴런과 경계 연결 개수를 기록한다. 성능에 따른 회로 재선정은 하지 않는다.

## 입력과 동역학

기탁된 R7 좌표를 씨앗으로 한 고정 Voronoi 평균으로 회색조 이미지를 망막 뉴런에 전달한다.
이는 망막 형태에서 추정한 평면 대응이며 각도 기반 수용장 검증을 마친 입력 모델이 아니다.
잘린 시야와 경계 밖 입력 누락 때문에 LC11의 생물학적 수량 특이성은 주장하지 않는다.
망막 광수용체는 세포 정체성에 따라 histamine 억제 부호를 지정한다.
다른 뉴런은 known_nt, 없으면 top_nt를 사용한다. GABA와 glutamate는 억제,
acetylcholine은 흥분으로 모델링한다. glutamate와 조절성/미지 부호는 민감도 분석 대상으로 기록한다.

W의 행은 postsynaptic, 열은 presynaptic이다. 원시 가중치는 시냅스 개수 × 전뉴런 부호이다.
각 행의 절댓값 합으로 나누고 gain 0.9를 곱한다. 이 정규화는 각 대조군에 독립적으로 적용한다.
업데이트: x[t+1] = (1-leak) x[t] + leak tanh(W x[t] + input[t]), leak=0.5.
입력 크기 1.0, 기본 제시 4 step, 자극 후 2 step. step은 실제 밀리초로 환산하지 않는다.
각 trial은 영 상태에서 시작하며 B에서 두 입력 사이에는 초기화하지 않는다.
출력층은 망막을 제외한 동일 뉴런 집합의 마지막 상태만 읽는다. 내부 가중치와 입력부는 학습하지 않는다.

## 자극과 분할

48×48 비중첩 원형 점, 4배 supersampling. train/validation/test의 난수 시드는 독립적이다.
0 이미지는 불가피하게 동일하지만, 양수 개수 이미지의 분할 간 해시 중복은 허용하지 않는다.
조건: 개별 반지름 범위 고정, 총 기하 면적 고정, 점 중심의 허용 공간 범위 고정,
개수와 총면적이 반대로 변하는 단서 충돌, 미학습 저대비·작은 점·준격자 배치.
허용 공간 범위 고정은 실현된 convex hull 또는 실제 밀도를 같게 만든다는 뜻이 아니다.
밝기·면적·공간 분포의 실제 값을 저장하고 단서와 개수의 상관을 보고한다.
0은 면적/밝기 일치가 불가능하므로 별도 층화한다.

A: train은 앞의 세 조건에서 개수당 조건당 12개, validation은 4개,
test는 다섯 조건에서 6개. 선형 ridge alpha=[0.01, 1, 100]를 A validation MAE로 선택한다.
각 그래프에 같은 탐색 예산을 쓴다. 공통 alpha=1 결과도 따로 저장한다.
특징 중심화·스케일은 train에서만 계산한다. 검증 후 train+validation 재학습은 하지 않는다.

B: 피연산자 0~5의 모든 순서쌍, 조건별 각 2회. 교환쌍은 동일 이미지의 순서만 바꾼다.
동일 개수 쌍은 독립 생성 이미지 두 개를 사용한다. gap=[0,2,6], duration=[2,4].
A에서 학습한 판독기를 그대로 고정하며 B에 대한 어떤 학습·선택도 하지 않는다.
개별 A와 B의 예측을 외부에서 더하지 않는다. 판독기 해시를 전후 확인한다.

C: A와 B와 독립적인 추가 자극으로 실행한다. a+b와 b+a를 하나의 조합 그룹으로 묶는다.
훈련 예산별 샘플은 중첩하고 test 조합은 고정한다. 합이 훈련에 존재했는지 별도로 보고한다.
0+0 및 5+5처럼 유일한 조합인 경계 합을 별도로 표시한다.
C의 새 출력층은 alpha=1로 고정한다. C test를 사용한 설정 선택은 하지 않는다.

## 대조군과 주 지표

재배선은 방향성 double-edge swap으로 각 뉴런의 입·출력 연결 수와 전뉴런별 가중치 집합,
양/음성 입력 연결 수를 보존한다. 시냅스 개수에 따른 입력 strength 보존은 보장하지 않는다.
연결당 성공한 swap 5회, 실제 바뀐 edge 비율 70% 이상을 요구한다.
각 그래프의 정규화 전후 가중치와 활동 포화율을 저장한다.
추가 대조: 뉴런 수/edge 수 일치 무작위 그래프, 실제 배선에서 가중치 위치 섞기,
재귀 가중치 제거, 밝기/면적/공간 영상 특징, 단순 pixel 적분기와 감쇠 적분기.
재귀 가중치 제거 모델에도 leak에 의한 자기 기억은 남는다.
현재 readout에서 망막을 제외하므로 재귀 가중치를 모두 제거하면 출력 상태가 영 상태로 남아
학습 정답 평균만 내는 상수 예측기가 된다. 이 상수 예측기의 MAE도 명시한다.
glutamate를 흥분 부호로 바꾼 별도 민감도 조건을 같은 절차로 평가한다.

주 지표는 B의 cue_conflict+ood, gap=2, duration=4에서 원시 연속 예측의 MAE이다.
합을 [0,10]으로 clipping하지 않는다. 보조 정확도는 반올림 예측이 정답과 같은 비율이다.
효과 = 실제 그래프 MAE - 각 재배선 MAE; 음수가 실제 그래프에 유리하다.
재배선 간 평균 효과의 bootstrap CI는 고정된 자극과 입력 설정에 조건부이다.
별도 자극/입력 반복을 하기 전에는 모집단 또는 개체 수준 신뢰구간으로 해석하지 않는다.
20개 재배선의 탐색적 순위만 보고하며 1개 실제 그래프와 공유한 trial을 독립 표본처럼 다루지 않는다.

## 중단과 다음 단계

체크섬 오류, 데이터 누출, 재배선 불변량 실패, 비유한 활동/예측이면 실행을 중단한다.
메모리/실행시간 초과 시 규모 변경은 새 설정으로 기록한다. 성능이 낮다는 이유로 중단하지 않는다.
현재 결과는 모델 및 합성 자극의 탐색적 예비실험이다. 확인 연구는 다중 자극 시드,
입력 범위/대비/시간 조건 반복, 부호 민감도, 공간·세포유형 제약 재배선 및
입력 대응 검토를 마친 뒤 새로운 test로 수행한다.
