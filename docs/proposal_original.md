# 프로젝트 기획안

## 연구 제목

**Can a Frozen Fruit Fly Connectome Generalize from Numerosity to Addition?**  
**고정된 초파리 신경 연결망은 수량 표현을 덧셈으로 일반화할 수 있는가?**

## 1. 연구 개요

본 프로젝트는 초파리의 실제 신경 연결 구조가 수량 정보를 표현하고 결합하는 데 유용한 계산 특성을 제공하는지 검증한다.

초파리 연결망을 반영한 인공 신경망의 내부 연결과 가중치를 고정하고, 제한된 출력층만 학습한다. 이후 하나의 점 집합에서 학습한 수량 판독기가 두 점 집합을 순차적으로 제시했을 때 그 합을 판독할 수 있는지 평가한다.

동일한 실험을 무작위 연결망과 연결 정도를 보존한 재배선 연결망에 수행한다. 실제 연결망에 이점이 나타나면, LC11 및 주변 회로에 대한 모델 내 억제·재배선 실험으로 그 이점을 설명하는 구조적 요인을 조사한다.

**핵심 기여는 수량 과제의 성공 여부를 넘어, 학습된 수량 표현의 재사용 가능성과 그 구조적 조건을 검증하는 데 있다.**

## 2. 선행연구와의 차별성

| 선행연구 | 이미 제시된 내용 | 본 프로젝트의 차별점 |
|---|---|---|
| Cho et al., 2026 | 초파리 연결 구조를 유지하면서 내부 가중치를 학습하여 미학습 덧셈 조합을 예측 | 내부 가중치를 고정하고, 수량 학습에서 덧셈으로의 전이를 평가 |
| Biological Processing Units, 2025 | 고정된 유충 연결망과 학습 가능한 입력·출력부로 이미지 분류·체스 수행 | 수량 표현이 다른 연산 상황에서도 재사용되는지 평가 |
| 초파리 connectome reservoir 연구 | 실제 연결망의 시계열 예측·동역학적 특성 분석 | 시각 단서를 통제한 수량 과제와 조합 일반화에 초점 |
| Bengochea et al., 2023 | 실제 초파리의 수량 구별 및 LC11 억제 효과 보고 | LC11 관련 구조가 모델의 수량 표현·전이에 기여하는 조건을 조사 |

초파리 연결망의 덧셈 학습과 입력·출력부만 학습하는 방식은 각각 선행연구가 있다. 또한 고정된 연결망의 동역학을 연결 정도·가중치가 맞춰진 대조군과 비교한 연구도 있으므로, 이 요소들만으로 독창성을 주장하지 않는다. [덧셈 연구](https://arxiv.org/abs/2610.10014), [BPU 연구](https://arxiv.org/html/2507.10951v1), [고정 연결망 분석](https://arxiv.org/abs/2606.17745)

본 프로젝트의 차별성은 다음 세 요소를 함께 검증하는 데 둔다.

1. **추가 덧셈 학습 없이 나타나는 수량→합산 전이**
2. **시각적 단서와 연결망 통계를 통제한 구조적 이점**
3. **수량 처리와 일반 시각 처리를 구분하는 회로 개입**

이는 확인한 선행연구를 바탕으로 제안하는 연구 공백이며, ‘세계 최초’라는 표현은 사용하지 않는다.

## 3. 연구 질문과 가설

**RQ1. 실제 연결 구조는 시각적 단서가 바뀌어도 유지되는 수량 표현을 지원하는가?**

- H1: 실제 연결망은 연결 정도 보존 대조군보다 새로운 점 크기·배치·밀도 조건에서 수량 판독 성능이 높다.

**RQ2. 하나의 집합에서 학습한 수량 판독기는 두 집합의 합에도 적용되는가?**

- H2: 단일 집합의 개수만 학습한 출력층을 고정한 뒤 두 집합을 순차 입력하면, 최종 신경 상태에서 합에 관한 정보를 판독할 수 있다.
- H3: 이러한 전이 성능은 실제 연결망에서 더 높으며, 단순 밝기 적분이나 일반적인 시간 기억만으로 설명되지 않는다.

**RQ3. 관찰된 이점은 특정 회로 및 연결 패턴과 관련되는가?**

- H4: 관련 회로의 억제 또는 선택적 재배선은 대조 회로 개입보다 수량 표현과 전이를 더 크게 저해한다.

각 가설은 독립적으로 평가한다. 수량 판독에 성공하더라도 덧셈 전이에 실패할 수 있다.

## 4. 데이터와 모델

### 4.1 연결망 선정

성체 초파리의 공개 연결망 가운데 LC11, 관련 시각 뉴런, 공간적 입력 대응 정보를 확인할 수 있는 자료를 우선 검토한다.

초기에는 계산량과 해석 가능성을 고려하여 **수천~1만 뉴런 규모의 시각 관련 부분 회로**를 목표로 한다. 실제 규모는 데이터 완전성과 예비 실행 결과로 확정한다.

회로 범위는 해부학적 기준으로 선정하고, 과제 성능을 보고 유리한 부분을 골라내지 않는다. 데이터 버전, 필터 기준, 제외 뉴런과 경계 연결을 모두 기록한다.

### 4.2 학습 범위

| 구성 요소 | 주 실험 |
|---|---|
| 내부 연결의 존재 여부 | 고정 |
| 내부 연결 가중치 | 연결 수 등 해부학적 자료로 구성한 뒤 고정 |
| 뉴런 동역학 | 사전에 정한 단순 모델 사용 |
| 시각 입력 변환 | 고정된 공간 대응 규칙 사용 |
| 출력층 | 선형 판독기만 학습 |

연결 수는 실제 생리학적 시냅스 강도의 직접 측정값과 구분한다. 흥분·억제 부호가 불확실한 연결은 별도 민감도 분석에 포함한다.

**입력층까지 학습하는 조건은 보조 실험으로 둔다.** 이를 통해 학습 가능한 입력부가 주요 계산을 대신 수행했는지 확인한다.

## 5. 실험 설계

### 실험 A. 시각적 단서에 강한 수량 표현

**목적:** 모델이 밝기나 면적을 넘어 개수에 관한 정보를 제공하는지 확인한다.

0~10개의 점 집합을 입력하고, 최종 신경 상태에서 개수를 예측하는 선형 판독기를 학습한다. 별도로 두 집합의 대소를 구별하는 출력층을 평가한다.

자극은 다음 조건군으로 구성한다.

- 총 점 면적을 맞춘 조건
- 개별 점 크기를 맞춘 조건
- 점이 분포하는 공간 범위를 맞춘 조건
- 개수와 총면적·밝기 단서가 반대 방향인 조건
- 학습에 없던 크기·배치·대비 조건

개수·밀도·면적은 서로 수학적으로 연결되므로 모든 단서를 동시에 같게 만들겠다고 가정하지 않는다. **조건군을 교차시키고, 학습에서 유용했던 단서가 테스트에서는 통하지 않도록 설계한다.**

평가는 정확도, 개수 예측 오차, 수량 비율별 대소 구별 성능으로 수행한다.

### 실험 B. 추가 학습 없는 수량→합산 전이

**목적:** 단일 집합에서 학습한 수량 표현의 재사용 가능성을 검증한다.

1. 실험 A에서 단일 집합의 개수 0~10을 판독하도록 학습한다.
2. 출력층을 포함한 모델 전체를 고정한다.
3. 개수가 각각 0~5인 집합 A와 B를 시간 간격을 두고 제시한다.
4. 두 번째 집합 이후의 신경 상태에 **동일한 수량 판독기**를 적용한다.
5. 예측값이 `A+B`와 얼마나 일치하는지 측정한다.

외부에서 두 집합의 개별 예측값을 더하는 연산은 사용하지 않는다. 출력층은 마지막 신경 상태만 읽는다.

이 실험은 ‘새로운 답 숫자’의 학습을 요구하지 않는다. 답 범위인 0~10은 단일 집합 학습에서 이미 경험하며, **새로운 것은 두 입력을 결합하는 상황**이다.

추가 대조 조건은 다음과 같다.

- 같은 합을 갖지만 구성 숫자가 다른 문제
- A와 B의 순서 교환
- 집합 사이 시간 간격 변경
- 자극 제시 시간과 점 크기 변경
- 총 밝기와 총 점 면적을 맞추거나 반대로 만든 문제
- 동일 자극의 반복 제시에 따른 적응·포화 검사

본 실험의 성공은 우선 **수량의 누적 또는 결합에 대한 전이 증거**로 해석한다. 기호적 덧셈 규칙을 습득했다는 주장은 별도 검증이 필요하다.

### 실험 C. 소량의 덧셈 학습과 미학습 조합 일반화

**목적:** 추가 학습 없는 전이가 약할 때에도, 실제 연결망이 덧셈 학습을 더 쉽게 만드는지 평가한다.

내부 연결망은 계속 고정하고, 제한된 덧셈 예제로 새로운 선형 출력층을 학습한다. 예제 수에 따른 학습 곡선과 미학습 조합 성능을 비교한다.

`a+b`와 `b+a`는 같은 데이터 분할에 배치한다. 출력값 자체를 처음 보는 문제와 피연산자 조합만 새로운 문제를 구분한다. 0+0처럼 특정 합을 만드는 조합이 하나뿐인 경계 문제는 별도로 보고한다.

실험 B가 ‘표현의 즉각적 재사용’을, 실험 C가 ‘학습 효율과 조합 일반화’를 평가하도록 역할을 구분한다.

### 실험 D. LC11 관련 회로의 모델 내 개입

실제 초파리에서는 LC11 억제가 수량 구별을 저해한다는 결과가 있다. 또한 LC11은 작은 물체의 시각 처리에도 관여하므로, 모델에서 성능이 감소했다는 사실만으로 수량 특이적 기능을 주장할 수는 없다. [수량 구별 연구](https://pubmed.ncbi.nlm.nih.gov/37453418/), [LC11 시각 처리 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC8716191/)

다음 개입을 비교한다.

- LC11 활동 억제
- LC11의 입력 또는 출력 연결 선택적 제거
- LC10a 등 다른 시각 뉴런 유형 억제
- 뉴런 수·연결 정도·기본 활동량을 맞춘 무작위 집단 억제
- 전체 연결 수를 유지한 국소 재배선

수량 과제와 함께 물체 유무·크기·위치 구별 과제를 평가한다. 일반 시각 기능의 손상으로 설명되는 효과와 수량 과제에서 추가로 나타나는 효과를 구분한다.

개입 직후의 손상과 출력층 재학습 후의 회복도 별도로 측정한다.

**진행 조건:** 해부학적으로 타당한 시각 입력 대응과 LC11 관련 경로가 확보되어야 한다. 임의의 뉴런에 입력을 주는 모델에서는 LC11의 생물학적 기능을 해석하지 않는다.

## 6. 대조군과 공정한 비교

| 대조군 | 확인할 질문 |
|---|---|
| 동일한 뉴런 수·연결 수의 무작위 연결망 | 일반적인 고차원 비선형 변환으로도 충분한가? |
| 방향성 입·출력 연결 정도 보존 재배선 | 각 뉴런의 연결 수를 넘어 정확한 배선이 중요한가? |
| 실제 배선에서 가중치 위치만 섞은 연결망 | 가중치의 분포와 배치 중 무엇이 중요한가? |
| 공간 또는 세포 유형 제약을 추가한 재배선 | 시각적 공간 조직이나 세포 구성만으로 설명되는가? |
| 순환 연결을 제거한 모델 | 시간적 누적에 재귀 연결이 필요한가? |
| 밝기·면적·영상 특징 기반 단순 모델 | 자극 생성 과정의 지름길로 풀리는가? |
| 단순 시간 적분기·일반 reservoir | 전이가 일반적 누적 특성만으로 설명되는가? |

모든 연결망에 동일한 입력 대응, 출력층 규모, 자극, 학습 데이터와 탐색 예산을 적용한다.

약한 대조군이나 초기화 차이가 연결망의 우위처럼 보일 수 있다는 선행 지적을 반영하여, 공통 설정 비교와 동일 예산의 검증 데이터 기반 설정 선택 결과를 함께 보고한다. [대조군·초기화 연구](https://arxiv.org/abs/2604.04033)

재배선 제약을 강화할 때에는 실제로 배선이 충분히 바뀌었는지도 확인한다. 정규화 전후 가중치 규모와 활동량을 기록하여, 단순한 신호 증폭 차이가 결과를 설명하는지 분석한다.

## 7. 평가 기준과 분석 계획

**주 평가 지표**

실험 B에서 시각 단서가 바뀐 조건의 합 예측 평균절대오차를 주 지표로 한다. 핵심 비교는 실제 연결망과 방향성 연결 정도 보존 재배선 집단의 차이다.

**보조 평가 지표**

- 정확한 합을 맞힌 비율
- 미학습 조합과 순서 교환에 대한 성능
- 시간 간격 변화에 대한 강건성
- 덧셈 학습 예제 수에 따른 성능
- 회로 개입에 따른 수량·시각 과제의 성능 변화

예비 실험에서는 최소 20개의 재배선 연결망을 평가하고, 최종 확인 실험의 수는 변동성과 계산 비용을 바탕으로 테스트 전에 확정한다.

이미지 수만 크게 늘려 통계적 확신을 과장하지 않도록, 재배선 연결망 간 변동과 자극 생성·입력 설정에 따른 변동을 구분한다. 결과는 효과 크기와 신뢰구간을 중심으로 보고한다.

주 과제·지표·대조군·데이터 분할·중단 기준을 사전 등록하며, 최종 테스트 결과를 보고 설정을 선택하지 않는다.

## 8. 결과별 해석

| 관찰 결과 | 가능한 결론 |
|---|---|
| 실제 연결망이 강한 대조군보다 전이 성능이 높음 | 해당 모델과 과제에서 배선 구조가 표현 재사용에 유리하다는 증거 |
| 수량 판독은 우수하지만 전이는 없음 | 수량 정보의 표현과 결합은 구별되는 계산 요구 |
| 덧셈을 조금 학습한 뒤에만 우위가 나타남 | 즉각적 전이보다 학습 효율에 구조적 이점이 있을 가능성 |
| 무작위 연결망과 성능이 유사함 | 이 조건에서는 생물학적 배선의 추가 이점이 확인되지 않음 |
| 단순 적분기가 같은 성능을 보임 | 일반적 누적 특성으로 설명될 가능성 |
| LC11 억제가 일반 시각 과제도 함께 저해함 | 수량 특이적 역할이라는 해석은 제한됨 |

성공 여부와 관계없이, **어떤 통계·입력 방식·학습 조건에서 이점이 나타나거나 사라지는지**를 연구 결과로 남긴다.

## 9. 수행 범위와 일정

아래 일정은 연구자 1명과 GPU 1대 수준을 가정한 약 12주의 초기 계획이며, 첫 단계의 실제 메모리·실행시간 측정으로 조정한다.

| 기간 | 작업 | 산출물 |
|---|---|---|
| 1~2주 | 연결망·세포 주석·시각 입력 대응 확인, 계산량 측정 | 데이터 명세와 실행 가능성 보고 |
| 3~4주 | 자극 생성기와 단순 기준 모델, 실험 A | 단서 통제 검증 및 수량 판독 결과 |
| 5~6주 | 추가 학습 없는 합산 전이, 실험 B | 주 평가 결과 |
| 7~8주 | 재배선·가중치·시간 적분 대조군 | 구조적 이점 분석 |
| 9~10주 | 소량 학습과 회로 개입, 실험 C·D | 일반화·회로 기여 분석 |
| 11~12주 | 확인 실험과 문서화 | 공개 코드·결과표·연구 보고서 |

**최소 완성 범위**는 실험 A·B와 연결 정도 보존 대조군 비교다. LC11 회로 분석과 다른 개체 연결망에서의 재현은 데이터 완전성과 계산 자원이 확보될 때 확장한다.

## 10. 최종 산출물과 주장 범위

최종 산출물은 다음과 같다.

- 시각적 단서와 데이터 누출을 검사할 수 있는 수량 자극 생성기
- 고정 연결망·재배선·단순 기준 모델 비교 코드
- 수량→합산 전이 및 미학습 조합 평가 자료
- 가능한 경우 LC11 관련 모델 개입 결과
- 실패 조건을 포함한 재현 가능한 연구 보고서

본 연구가 입증할 수 있는 것은 **초파리 연결망에서 유래한 특정 계산 모델의 특성**이다. 실제 초파리가 동일한 동역학이나 연산 방식으로 덧셈한다는 결론은 포함하지 않는다.

생물학적 후속 연구로 연결할 경우에는 모델이 예측한 자극 조건별 행동 변화와 LC11 관련 신경 활동을 실제 실험에서 검증한다.
