# 후속 연구 작업

현재 프로젝트는 실행 코드, 실제 데이터 명세, A/B 예비실험과 C 확장을 제공한다.
이 문서는 아직 수행하지 않은 작업을 명시한다.
공식 FlyWire 원본과 모델 부분 회로의 완전 일치 검증은 완료했다.

| 우선순위 | 작업 | 완료 판단 기준 |
|---|---|---|
| 1 | 예비 결과의 단서 의존성 평가 | A의 조건별 오차, cue audit, 영상 단서/적분 대조군을 함께 해석 |
| 2 | 다중 자극 시드와 입력 설정 반복 | 최소 3개 자극 시드와 사전에 정한 시야 crop/대비 변형에서 재현 |
| 3 | 공간·세포 유형 제약 재배선 | 제약별 실제 edge 변경률, signed degree, 가중치·활동량 진단 통과 |
| 4 | 동역학 설정 검증 비교 | 같은 A validation 탐색 예산으로 leak/gain/input scale 선택, 새로운 test에서 검증 |
| 5 | 입력 대응 독립 검토 | PCA 투영·R7 ommatidia·신경 중첩의 타당성과 LC11까지의 경로 검토 |
| 6 | 실험 D | LC11·LC10a·수/정도/기초 활동량 일치 집단 개입, 물체 유무/크기/위치 대조, 출력층 재학습 회복 분석 |
| 7 | 반복 제시 적응·포화 검증 | 같은 이미지 반복과 독립 이미지 반복의 시간별 상태 및 예측 저장 |
| 8 | 확인 연구 외부 사전등록 | 표본 수, 주 지표, 고정 설정, 중단 기준, 새 test seed를 결과 열람 전에 등록 |
| 9 | 다른 개체 연결망 | 동일한 해부학적 규칙과 입력 대응을 다른 성체 자료에 적용 |

현재 signed tanh 모델에는 생물학적 적응·시냅스 단기 가소성 모델이 없다.
주 실험의 음성 결과를 없애기 위해 모델을 바꾸지 않는다. 변경한 모델은 별도 탐색 가설로
버전 관리하고 새 test 자극으로 평가한다.

LC11 모델 개입 코드를 추가하는 것 자체보다 입력과 대조 과제의 타당성을 먼저 확보한다.
임의로 억제한 뉴런의 성능 변화만으로 생물학적 수량 특이성을 주장하지 않는다.
