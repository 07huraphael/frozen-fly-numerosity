# 데이터 품질 점검 기록

2026-10-23. 실제 자료의 첫 실행에서 재배선 중 예외가 발생했다.
원인은 입력 파일의 일부 동일 presynaptic/postsynaptic 뉴런쌍이 여러 행에 존재하는 것이었다.
가공 기탁 README는 뉴런쌍별 grouped graph로 설명하지만 이를 그대로 단순 그래프로 취급할 수 없었다.
초기 선택에서는 34,002행 가운데 고유 뉴런쌍이 33,587개였다.

수정한 처리 규칙은 다음과 같다.

1. 해부학적 이웃 선택 전에 뉴런쌍별 `syn_count`를 합한다.
2. 부분 회로 및 경계에 접하는 전체 행도 뉴런쌍별로 합한다.
3. 합산한 뉴런쌍의 시냅스 수에 최소 5개 기준을 적용한다.
4. `Graph` 생성 시 병렬 행을 거부하여 재배선 불변량이 깨지는 일을 막는다.

이 정책은 병렬 행을 시냅스 개수의 가산 자료로 해석한다. 가공 기탁의 중복 행이
원래 neuropil별 집계에서 유래하는지 또는 별도 처리 산물인지의 최종 대조는 수행하지 않았다.
확인 실험 전 상위 `proofread_connections_783.feather`와 대조할 필요가 있다.
현재 결과 보고서의 데이터 범위는 **해당 가공 기탁을 위 규칙으로 합산한 모델**이다.

이전 부분 실행은 `results/pilot_failed_parallel_rows`에 남겼고 최종 비교에서는 제외했다.
이는 연구 성능에 따른 회로 선택이 아니라 데이터 구조 오류를 해결한 수정이다.
수정 후 전체 파이프라인을 새로 실행한다.

## 원본 대조 완료

기탁 MD5 `f48f972d262323a102aed49af1396b8a`를 확인했다.
SHA-256은 `24f960ae3e7d4f8cd30db3b62e99fb5179cc3d1e76d8c155bfb441e9737d3faf`이다.

공식 원본을 뉴런쌍별로 합산해 같은 기준으로 추출한 결과,
모델의 5,978개 뉴런 선택과 35,483개 연결의 양 끝점 및 시냅스 수가 모두 정확히 일치했다.
이는 앞서 남긴 **모델 부분 회로의 상위 원본 대조 필요**를 해소한다.
